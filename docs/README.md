# Hecatron's documentation

- **[User guide](guide/README.md):** using `hct` in a project: every
  command, the project's configuration and hooks, toolchains and their
  versions, generated CI, and each report.
- **[Contributor guide](contributing/README.md):** working on hecatron
  itself: the architecture, the modules, how a command flows through them,
  the install engine, testing, releasing, adding a language, and the design
  record with the decisions behind it.
- **[Reference for AI agents](agents.md):** commands, results,
  configuration and overrides in brief; `hct help agents` prints it for the
  installed version.
